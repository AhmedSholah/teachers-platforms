1. التوجيه بالنطاق الفرعي واستخراج الـ Subdomain بأمان

لاستخراج اسم المعلم من الرابط (سواء في السيرفر SSR أو المتصفح Client)، تم إنشاء Composable محمي ضد هجمات الـ Host Header Injection واختراق المسارات:

// app/composables/useSubdomain.ts
export const RESERVED_SUBDOMAINS = new Set([
  'www', 'admin', 'administrator', 'api', 'app', 'auth', 
  'billing', 'cdn', 'dashboard', 'dev', 'login', 'signup', 'status'
])

const SUBDOMAIN_REGEX = /^[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?$/

export const useSubdomain = () => {
  const url = useRequestURL()
  const route = useRoute()

  return computed<string | null>(() => {
    let candidate: string | null = null

    // تجربة سريعة في بيئة التطوير عبر: ?subdomain=ahmed
    if (import.meta.dev) {
      const q = route.query?.subdomain || route.query?.tenant
      if (typeof q === 'string' && q.trim()) candidate = q.trim().toLowerCase()
    }

    if (!candidate) {
      const host = url.hostname.toLowerCase()
      if (/^(\d{1,3}\.){3}\d{1,3}$/.test(host) || host === '::1') return null

      // Localhost: teacher1.localhost
      if (host.endsWith('localhost')) {
        const parts = host.split('.')
        if (parts.length > 1 && parts[0] !== 'localhost') candidate = parts[0]
      } 
      // الإنتاج: teacher1.platform.com
      else {
        const parts = host.split('.')
        if (parts.length >= 3) candidate = parts[0]
      }
    }

    if (!candidate) return null
    if (!SUBDOMAIN_REGEX.test(candidate)) return null
    if (RESERVED_SUBDOMAINS.has(candidate)) return null

    return candidate
  })
}
⚠️ قواعد أمان هامة:
  • فحص قاعدة البيانات: تأكد دائماً أن المعلم موجود في الـ DB وإلا ارمِ خطأ 404.
  • عزل الـ Cookies: لا تضع الـ Cookies بنطاق عام Domain=.platform.com حتى لا تشارك الجلسات بين منصات المعلمين المختلفة.

2. تنظيم الصفحات بملفات منفصلة دون تكرار v-if/else

بدلاً من كتابة v-if="subdomain" داخل كل صفحة، نستخدم `app/router.options.ts` لتقسيم مجلدات الصفحات في Nuxt:

app/pages/
├── main/                       <-- النطاق الرئيسي فقط (platform.com)
│   ├── index.vue               --> platform.com/ (صفحة التسويق)
│   └── dashboard.vue           --> platform.com/dashboard (لوحة إدارة المعلم)
│
├── tenant/                     <-- النطاقات الفرعية فقط (teacher.platform.com)
│   ├── index.vue               --> teacher.platform.com/ (بوابة كورسات الطلاب)
│   └── dashboard.vue           --> teacher.platform.com/dashboard (لوحة متابعة الطالب)
│
└── login.vue                   <-- صفحة مشتركة تعمل في كلا النطاقين!

الكود المسؤول عن إعادة كتابة المسارات في app/router.options.ts:

// app/router.options.ts
import type { RouterConfig } from '@nuxt/schema'

export default <RouterConfig>{
  routes: (_routes) => {
    let isSub = false

    if (import.meta.server) {
      const event = useRequestEvent()
      const host = event ? getRequestHost(event).toLowerCase() : ''
      isSub = host.includes('.') && !host.startsWith('www')
    } else {
      isSub = window.location.hostname.includes('.') && !window.location.hostname.startsWith('www')
    }

    const shared = _routes.filter(r => !r.path.startsWith('/main') && !r.path.startsWith('/tenant'))

    if (isSub) {
      const tenantRoutes = _routes
        .filter(r => r.path.startsWith('/tenant'))
        .map(r => ({ ...r, path: r.path.replace(/^\/tenant/, '') || '/' }))
      return [...tenantRoutes, ...shared]
    } else {
      const mainRoutes = _routes
        .filter(r => r.path.startsWith('/main'))
        .map(r => ({ ...r, path: r.path.replace(/^\/main/, '') || '/' }))
      return [...mainRoutes, ...shared]
    }
  }
}

3. معمارية التوليد الهجين (Hybrid Rendering)

في nuxt.config.ts نقوم بتحديد طريقة عمل كل جزء في المنصة:

// nuxt.config.ts
export default defineNuxtConfig({
  routeRules: {
    // 1. الصفحة الرئيسية: SSG (توليد مسبق لسرعة خارقة)
    '/': { prerender: true },

    // 2. صفحات المعلمين: ISG / SWR (توليد عند أول طلب وكاش لمدة ساعة)
    '/tenant/**': { swr: 3600 },

    // 3. لوحات التحكم: SPA كاملة (بدون SSR لتخفيف الحمل وسرعة التفاعل)
    '/dashboard/**': { ssr: false },
    '/login': { ssr: false }
  }
})

4. تفريغ الكاش لحظياً (Cache Busting) مع Convex

عندما يقوم المعلم بتعديل كورس في Convex، نرسل Webhook لحذف النسخة المخبأة (Cache) في السيرفر:

1. إنشاء مسار التفريغ في Nuxt:

// server/api/revalidate.post.ts
export default defineEventHandler(async (event) => {
  const body = await readBody(event)
  const config = useRuntimeConfig()

  if (getHeader(event, 'x-revalidate-secret') !== config.revalidateSecret) {
    throw createError({ statusCode: 401, statusMessage: 'Unauthorized' })
  }

  const { subdomain } = body
  const storage = useStorage('cache')
  const keys = await storage.getKeys('nitro:handlers')

  // حذف كاش المعلم المحدد فوراً
  for (const key of keys) {
    if (key.includes(subdomain)) {
      await storage.removeItem(key)
    }
  }

  return { revalidated: true }
})

2. استدعاء التفريغ من Convex Action:

// convex/revalidate.ts
import { internalAction } from "./_generated/server"

export const bustTenantCache = internalAction({
  args: { subdomain: v.string() },
  handler: async (ctx, args) => {
    await fetch(`https://yourplatform.com/api/revalidate`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'x-revalidate-secret': process.env.REVALIDATE_SECRET
      },
      body: JSON.stringify({ subdomain: args.subdomain })
    })
  }
})

5. المعادلة الذهبية (SEO + أداء فائق + Live Sync)

هذا المزيج يوفر أفضل تجربة ويب ممكنة بدون أي تضحيات:

الميزة كيف تتحقق؟ النتيجة
SEO مثالي (100/100) الـ HTML يتم توليده عبر الـ SSR/ISG بالكامل مع العناوين والـ Meta Tags جوجل وواتساب يرون المحتوى وصور المشاركة فوراً بدون جافاسكريبت
أداء فائق (TTFB < 20ms) الكاش يخدم آلاف الطلاب بدون أي استهلاك لقاعدة بيانات Convex فتح الصفحة فوري على الموبايل وبأقل تكلفة خوادم ممكنة
تحديث مباشر (Live Sync) بمجرد فتح الصفحة يفتح الـ WebSocket في الخلفية تعديل الأسعار أو نفاد المقاعد يظهر مباشرة أمام الطالب دون تحديث الصفحة

6. الحل الجاهز الرسمي: مكتبة nuxt-convex

لست بحاجة لكتابة كود الاتصال بالـ WebSockets والـ SSR يدوياً؛ توفر مكتبة nuxt-convex كل ذلك تلقائياً:

# 1. التثبيت
pnpm add convex nuxt-convex
// 2. تفعيلها في nuxt.config.ts
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    'nuxt-convex'
  ]
})
<!-- 3. الاستخدام بسطر واحد داخل صفحاتك -->
<script setup lang="ts">
import { api } from '#convex/api'

const subdomain = useSubdomain()

// سطر واحد يتكفل بالـ SSR، تمرير البيانات بدون Double-Fetch، والـ WebSocket المباشر!
const { data: teacher, isLoading } = await useConvexQuery(api.teachers.getBySubdomain, {
  subdomain: subdomain.value!
})
</script>

<template>
  <div v-if="teacher">
    <h1>منصة {{ teacher.name }}</h1>
    <p>سعر الكورس: {{ teacher.courses[0].price }} ج.م</p>
  </div>
</template>
✨ النتيجة النهائية: كود صفحات نظيف جداً، روابط نظيفة، حماية كاملة، وأداء يعادل أكبر منصات التعليم العالمية.
